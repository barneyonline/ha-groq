# README artwork and screenshots

The banner pair follows the [project wiki artwork](https://github.com/barneyonline/ha-groq/wiki): cyan glass, a ceramic smart home, cloud, voice and vision symbols, and small amber accents. Both banners are 1200 × 400 pixels and use the subtitle **Text, voice and vision for Home Assistant**.

The banners were generated with the built-in image generation tool using the wiki Home banner as a style reference. The light version was derived from the dark version to preserve the composition and typography. Embedded image metadata was removed from the final files.

## Banner prompts

Dark: Create a wide panoramic Groq README banner matching the wiki's refined midnight teal and cyan glass artwork. Place the title "Groq" and subtitle "Text, voice and vision for Home Assistant" on the left. Arrange a white ceramic smart home, glass cloud, speech waveform, speech bubble, globe and camera aperture on the right. Keep the composition spacious, all objects inside comfortable margins, and the typography clear. No other text, logos, watermarks or interface elements.

Light: Preserve the dark banner's composition, objects, text and typography. Use pale icy teal surroundings, soft daylight, frosted cyan glass, a warm-white ceramic house, tiny amber accents and deep midnight teal text. No added objects, text or interface elements.

## Screenshot provenance

Captured on 31 October 2026 from the live Groq v2.1.0 integration in Home Assistant, using the built-in browser after the user selected it in place of Safari. The captures use Home Assistant's light theme. Each screenshot is cropped to its configuration dialog; browser chrome, the sidebar, account details and local addresses are outside the crop. Forms were closed without submitting changes.
